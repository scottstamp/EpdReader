⚠️ Bluetooth Disabled (Secure Context Required)

Web Bluetooth is unavailable. Browsers require a Secure Context (HTTPS or localhost) to run Web Bluetooth APIs.

How to fix on iOS (iPhone/iPad):
Standard iOS Safari does not support Web Bluetooth. Please download a Web Bluetooth browser from the App Store, such as Bluefy or WebBLE, and open this URL within that app.
How to fix on Android Chrome:
  1. Open a new tab in Chrome and go to:
    chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Set the flag to Enabled.
  3. Paste this page's origin address into the text box:
    http://192.168.x.x:8000
  4. Relaunch Chrome (tap 'Relaunch' at bottom) and reload this page.
How to fix:
Please load this page over HTTPS or run it locally as localhost (e.g. http://localhost:8000).
